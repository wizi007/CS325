
# Description
This script generates a review summary of products using a large language model as the classifier. Product reviews are classified into positive, neutral and negative by the LLM.
## Prerequisite
Download ollama using this link https://ollama.com/download

The reviews for each file should be downloaded in a text file ending with '_reviews.txt'. The path for these text file should be noted as it is needed in the code.

## Setup
To call the phi-3 API generated by ollama, run `ollama serve`

Create a new virtual environment and install the dependency packages by running `pip install --file requirements.yaml`

We will be using the tinyllama model. Begin the ollama model with `ollama run tinyllama`

## Running the script
Run the script in the environment with the command `python main.py`. The script is limited to 20 reviews per product. This number can be changed within the code.
