
# Description
This scripts scrapes the reviews of specific product items listed on ebay. The product items chosen are among the Xbox series.
The Xbox series considered from recent to later are listed below
- Xbox series X
- Xbox series S
- Xbox one X
- Xbox one S
- Xbox 360

## Setup

Create a new virtual environment and install the dependency packages by running `pip install --file requirements.yml`

## Running the script
Run the script in the environment with the command `python main.py`
